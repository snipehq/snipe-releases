# Snipe 1.1.0

## ✨ What's new

- Edit metadata - hold Option in the Finder menu, choose Edit Meta to change title, artist, and more for video, audio, and images. Only shows fields you can actually change.
- Conversions keep metadata by default - names, dates, and locations carry over. Turn it off in the converter or under Settings → Quick Menu → Defaults.
- Finder conversions use your settings - pick quality, size, sound, and more once in Settings → Quick Menu → Defaults, and every quick conversion from Finder follows them.
- A menu that matches Finder - cleaner to read, with Regular or Clear style on the latest macOS. Clearer tick when you point at a choice, with separate sound and vibration switches in Settings.
- Edit several files side by side - each file opens its own window. Instant actions like Mute or Clean Meta won't close what you're editing.

## 🐞 Bug fixes

- Clicking the menu no longer changes your Finder selection.
- No more faint box around the menu on dark backgrounds.
