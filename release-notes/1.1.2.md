# Snipe 1.1.2

## ✨ What's new

- Photos to PDF now use the same page size by default, so sharing and printing looks clean.
- New PDF page size choice: A4, US Letter, or Original. Find it in Converter settings and Quick Menu defaults.

## 🐞 Bug fixes

- Fixed PDFs where every page had a different size.
- Fixed portrait photos turning sideways in PDFs.
- Fixed PDF to PDF losing selectable text.
- Photos make smaller PDFs with quality setting, screenshots stay sharp.
- Small icons no longer become huge poster pages.
- Splitting a very short audio or video file no longer crashes the app — it now says the file is too short to split.
